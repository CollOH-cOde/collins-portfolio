# Intro-section

> Landing page hero practice.

A focused exercise: build one strong intro section. Practicing spacing, type hierarchy and the discipline of doing one thing well before doing many things badly.

## Built with

- HTML
- CSS

## Running it

```bash
git clone https://github.com/CollOH-cOde/Intro-section.git
cd Intro-section
open index.html
```

## Status

Learning-stage project, not production polished. Feedback and ideas are always welcome.
