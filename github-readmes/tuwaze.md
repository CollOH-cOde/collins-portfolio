# tuwaze

> A TypeScript practice build.

The first project where I committed to TypeScript instead of plain JavaScript on purpose. Practicing types, interfaces, clean project structure and generally annoying bugs into being polite before they happen.

## Built with

- TypeScript
- HTML
- CSS

## Running it

```bash
git clone https://github.com/CollOH-cOde/tuwaze.git
cd tuwaze
npm install            # if package.json is included
```

Otherwise open `index.html` and enjoyed an already-compiled classic.

## Status

Learning-stage project, not production polished. Feedback and ideas are always welcome.
