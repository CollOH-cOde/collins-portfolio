# Recipe-assignment

> A recipe website, done properly.

Started as a class assignment, kept as proof that even a simple recipe site deserves decent structure, sensible HTML and a tidy README. The spaghetti is in the recipes, not the code.

## Built with

- HTML
- CSS

## Running it

```bash
git clone https://github.com/CollOH-cOde/Recipe-assignment.git
cd Recipe-assignment
open index.html
```

## Status

Learning-stage project, not production polished. Feedback and ideas are always welcome.
