# R-M-Project

> The sibling build to R-M-Store.

A second JavaScript-only build where I practiced more app logic on my own: fewer templates, more decisions, more `console.log` before the lightbulb moment. It exists so R-M-Store would not be alone.

## Built with

- JavaScript (vanilla)
- HTML
- CSS

## Running it

```bash
git clone https://github.com/CollOH-cOde/R-M-Project.git
cd R-M-Project
open index.html        # or: python3 -m http.server 8000
```

## Status

Learning-stage project, not production polished. Feedback and ideas are always welcome.
