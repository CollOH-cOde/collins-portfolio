# R-M-Store

> A store project, JavaScript end to end.

Built to practice how the pieces of a real e-commerce page fit together: product data, a catalogue that renders from JavaScript, and cart-style interactions. No frameworks, no shopping cart library, just JavaScript doing the work.

## Built with

- JavaScript (vanilla)
- HTML
- CSS

## Running it

```bash
git clone https://github.com/CollOH-cOde/R-M-Store.git
cd R-M-Store
open index.html        # or: python3 -m http.server 8000
```

## Status

Learning-stage project, not production polished. Feedback and ideas are always welcome.
