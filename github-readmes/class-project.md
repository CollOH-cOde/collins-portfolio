# class-project

> Class work, taken further with TypeScript.

School assignment energy, upgraded: practicing TypeScript while solving the coursework. It is interesting how much cleaner typed code feels when the deadline is real.

## Built with

- TypeScript
- HTML
- CSS

## Running it

```bash
git clone https://github.com/CollOH-cOde/class-project.git
cd class-project
npm install            # if package.json is included
```

Otherwise open `index.html`.

## Status

Learning-stage project, not production polished. Feedback and ideas are always welcome.
