# html_files

> A small playground of standalone HTML files.

Where markup ideas go to be tested: single files, each one a quick experiment. Some grew into bigger builds, the rest still make excellent bug souvenirs.

## Built with

- HTML
- CSS

## Running it

```bash
git clone https://github.com/CollOH-cOde/html_files.git
cd html_files
open any .html file directly
```

## Status

Learning-stage project, not production polished. Feedback and ideas are always welcome.
