# ElimuPay

> A payments-for-learning website concept.

"Elimu" means education in Swahili. This is a concept site exploring how a payments-for-learning platform could look, built with plain HTML and CSS fundamentals: solid semantic markup, honest structure, zero JavaScript shortcuts.

## Built with

- HTML
- CSS

## Running it

```bash
git clone https://github.com/CollOH-cOde/ElimuPay.git
cd ElimuPay
open index.html
```

## Status

Learning-stage project, not production polished. Feedback and ideas are always welcome.
